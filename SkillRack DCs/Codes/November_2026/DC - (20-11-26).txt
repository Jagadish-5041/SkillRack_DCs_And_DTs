Problem Statement :-

X Occurs Exactly X Times in DC (Daily Challenge) in SkillRack in Python - Programming

Code :-

N = int(input().strip())

values_list = list(map(int , input().strip().split()))

X = int(input().strip())

X_frequency = sum(1 for value in values_list if(value == X))

print(("YES") if(X_frequency == X) else ("NO"))
