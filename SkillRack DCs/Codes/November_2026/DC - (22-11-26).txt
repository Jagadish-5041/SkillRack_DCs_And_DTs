Problem Statement :-

Arithmetic Progression Till C in DC (Daily Challenge) in SkillRack in Python - Programming

Code :-

A , B , C = map(int , input().strip().split())

current_value = A

offset_value = B

maximum_value = C

while(current_value <= maximum_value):
    
    print(current_value , end = " ")
    
    current_value = (current_value + offset_value)
