Problem Statement :-

Parentheses Pattern in DC (Daily Challenge) in SkillRack in Python - Programming

Code :-

N = int(input().strip())

asterisks_string = ("*" * N)

open_parenthesis_string = ("(" * N)

closed_parenthesis_string = (")" * N)

half_rows_pattern_list = [(asterisks_string[ : (N - i)] + open_parenthesis_string[ : i] + closed_parenthesis_string[ : i] + asterisks_string[ : (N - i)]) for i in range(1 , (N + 1))]

pattern_rows_list = (half_rows_pattern_list + half_rows_pattern_list[ : -1][::-1])

print(*pattern_rows_list , sep = "\n")
