Problem Statement :-

Right Triangle Digit Pattern in DT (Daily Test) in SkillRack in Python - Programming

Code :-

N = int(input().strip())

C = 1

while(N > 0):
    
    for j in range(1 , (C + 1)):
        
        print((N % 10) if(N > 0) else ('*') , end = " ")
        
        N = (N // 10)
    
    print()
    
    C = (C + 1)
