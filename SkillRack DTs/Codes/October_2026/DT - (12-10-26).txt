Problem Statement :-

Alternate - Append And Prepend in DT (Daily Test) in SkillRack in Python - Programming

Code :-

def is_odd(N):
    
    return ((N & 1) == 1)

S = ""

for position in range(1 , (int(input().strip()) + 1)):
    
    word_string = input().strip()
    
    S = (S + word_string) if(is_odd(position)) else (word_string + S)

print(S)
