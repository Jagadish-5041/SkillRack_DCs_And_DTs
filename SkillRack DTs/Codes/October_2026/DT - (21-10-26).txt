Problem Statement :-

Previous Value - Unit Tenth Digits Product in DT (Daily Test) in SkillRack in Python - Programming

Code :-

def get_unit_digit(N):
    
    return (N % 10)

def get_tenth_digit(N):
    
    return ((N % 100) // 10)

N = int(input().strip())

values_list = list(map(int , input().strip().split()))

print(*[(get_unit_digit(values_list[(index - 1)]) * get_tenth_digit(values_list[(index - 1)])) for index in range(1 , N)])
